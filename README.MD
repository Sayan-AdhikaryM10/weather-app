# 🌍 World Map Weather App

An interactive, map-based weather dashboard that allows users to click anywhere on the globe to get real-time weather data. Built with an intuitive glassmorphism UI, this application completely replaces traditional text-based city searches with a visual, geographic exploration experience.

## ✨ Features

- **Interactive Global Map**: Seamlessly pan and zoom across a complete world map using Leaflet.js.
- **Coordinate-Based Weather**: Click any location (land or sea) to fetch exact local weather conditions using latitude and longitude.
- **Real-Time Data**: Displays current temperature, weather description, humidity percentage, and wind speed.
- **Modern UI/UX**: Features a floating, glassmorphism-styled weather panel that dynamically appears over the map.
- **Responsive Design**: Fully responsive layout that works perfectly on both desktop and mobile devices.

## 🚀 Technologies Used

- **HTML5 & CSS3**: Structure and modern styling (Flexbox, Backdrop-filter for glass effect).
- **Vanilla JavaScript (ES6+)**: Core logic, asynchronous API calls, and DOM manipulation.
- **[Leaflet.js](https://leafletjs.com/)**: Open-source JavaScript library for mobile-friendly interactive maps.
- **[OpenStreetMap](https://www.openstreetmap.org/)**: Map tile provider.
- **[OpenWeatherMap API](https://openweathermap.org/api)**: Real-time weather data provider.

## 🛠️ Installation & Setup

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/world-weather-app.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd world-weather-app
   ```

3. **Get a free API Key:**
   - Go to [OpenWeatherMap](https://openweathermap.org/) and create a free account.
   - Generate a new API key from your account dashboard.

4. **Add your API Key:**
   - Open `script.js` in your preferred code editor (like VS Code).
   - Locate the `API_KEY` variable at the top of the file.
   - Replace `'YOUR_API_KEY_HERE'` with your actual OpenWeatherMap API key.

5. **Run the app:**
   - Simply double-click the `index.html` file to open it in your web browser, or use a tool like Live Server in VS Code.
